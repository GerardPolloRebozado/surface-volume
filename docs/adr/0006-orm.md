# ADR 0006 - Database ORM decision

- Status: **Accepted**
- Date: 2026-11-12
- Deciders: @gerardPolloRebozado

NestJS has different [integrations](https://docs.nestjs.com/data/overview)

The main two options where either Prisma or Drizzle or TypeORM, the team has already worked with both and they are the one that have most similar SQL queries syntax, migration on prisma are more mature than drizzle and there is more documentation and community support for Prisma, but there was a drawback, nestjs does not have an oficial plugin for it, but drizzle and TypeORM has one. TypeORM has a more similar approach as NestJS with the decorators and syntax but migrations are way more manual and has quite some boilerplate, prisma has way easier migrations and better when working in teams. After testing the three of them we decided to go with Prisma and make our own integration.
